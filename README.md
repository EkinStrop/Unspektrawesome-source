# Unspektrawesome

Unspektrawesome is an Android camera app with a live RAW viewfinder, Vulkan image processing, and Spektra film simulation.

This repository contains the Android implementation with Spektra integration.

## Credits

The Spektra rendering code was adapted for Android through Unmcrawesome from [Spektrafilm OFX](https://github.com/chaert-s/spektrafilm-ofx) by **Aedan Diez (chaert-s)** and its contributors.

Spektrafilm OFX builds on [Spektrafilm](https://github.com/andreavolpato/spektrafilm) by **Andrea Volpato**, including its film modeling and profile-generation work. The Android integration modifies the upstream renderer and build setup.
